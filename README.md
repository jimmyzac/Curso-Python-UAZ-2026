# Curso interactivo de Python

Primera versión del curso para ejecutarse desde Google Colab.

## Archivos
- `python_economistas.py`: motor y contenido del curso.
- `COLAB_INICIO.py`: contenido que se puede pegar en una única celda de Colab.

## Uso en GitHub + Colab

1. Crea un repositorio, por ejemplo `curso-python`.
2. Sube `python_economistas.py` a la rama `main`.
3. Sustituye `TU_USUARIO` en la celda de Colab por tu usuario de GitHub.
4. Comparte el Colab con los alumnos en modo lectura.

La primera versión genera un reporte JSON local. No contiene credenciales ni conexión a Google Sheets.
